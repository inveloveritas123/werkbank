# DPIA-SCREENING (Art. 35 Abs. 1)
| Hochrisiko-Indikator | Zutreffend | Begründung |
|---|---|---|
| Profiling/Scoring | nein | keine Bewertung von Personen |
| Besondere Kategorien (Art. 9) großem Umfang | nein | keine Art-9-Daten |
| Systematische Überwachung | nein | keine |
| Neue Technologie/KI unklare Risiken | nein | klassische CRUD-Verwaltung, EU-only, PII-arm |
| Automatisierte Entscheidung mit Rechtswirkung | nein | keine |
**Ergebnis:** kein Indikator erfüllt → keine DSFA erforderlich (dokumentierte Verneinung).
