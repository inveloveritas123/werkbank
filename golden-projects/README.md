# Golden Projects

Standardisierte Prüfprojekte mit **festem Soll-Ergebnis**. WERKBANK verbessert sich, indem es
diese immer wieder durchläuft und gegen ihr Soll misst — nicht, indem es frei optimiert.

Jedes Projekt enthält (mind. `SPEC.md`; Projekt 01 vollständig als Vorlage):
```
SPEC.md                 # Ziel, Feature, Akzeptanzkriterien (testbar)
EXPECTED_OUTPUTS.md     # welche Artefakte/Dateien müssen entstehen
PRIVACY_EXPECTATIONS.md # DSGVO-Soll (welche Gates, welche Artefakte)
SECURITY_SEEDS.md       # bewusst eingebaute Schwachstellen, die die Gates fangen MÜSSEN
SCORING.md              # projektspezifische Punkte-Anmerkungen (Basis: ../../SCORING-MATRIX.md)
```

Reihenfolge & Akzeptanz stehen in `../BACKLOG.md`. Bewertung in `../SCORING-MATRIX.md`.
Verbesserungsregeln in `../SELF-IMPROVEMENT.md`.
